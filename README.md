# Laboration 2

Den här lösningen består av en enkel Todo-applikation skapad med React och TypeScript. Användare kan skapa och radera todo-föremål samt ändra dess status. Uppgiften har lett till en bättre förståelse för tillståndshantering i React och nya kunskaper i hur man kan hämta och använda data med useEffect. 

## Funktionalitet
* Skapa nya todo-föremål med titel, beskrivning och status. 
* Validering av användarinmatning. 
* Ändra status mellan "ej påbörjad", "pågående" och "avklarad".
* Radera ett todo-föremål.
* Reponsiv layout. 
* Laddningsindikator från react spinners när todos hämtas in. 

## Övrigt
* Lösningen har inte publicerats utan presenteras med en videopresentation. 
* Ett särskilt backend API med full CRUD för todo-föremål har skapats med hapi.js.
